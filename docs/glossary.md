# 용어집 (Glossary)

FabGraph 문서와 코드에서 자주 쓰는 용어를 한곳에 정리한 문서입니다.

## 핵심 제품 용어

### FabGraph
반도체 제조 데이터를 자연어로 탐색하고, 그래프 / 테이블 / 차트 / 채팅으로 함께 확인할 수 있게 만드는 분석 워크스페이스입니다.

### thin slice
기능 범위는 작지만, 사용자 입력부터 화면 렌더링까지 끝까지 이어지는 최소 기능 흐름을 뜻합니다.

### fallback
실제 DB나 외부 의존성이 없을 때, 샘플 데이터나 대체 경로로 동작을 유지하는 방식입니다.

### workspace
그래프 / 테이블 / 차트 / 채팅이 함께 붙어 있는 작업 화면을 뜻합니다.

## 데이터 / 아키텍처 용어

### Hybrid DB
정형 데이터 조회는 PostgreSQL, 관계 탐색은 Neo4j처럼 서로 다른 DB를 역할에 맞게 함께 사용하는 구조입니다.

### artifact
백엔드가 프론트엔드에 전달하는 구조화된 결과물입니다. 예: table, graph, chart, summary.

### Router Agent
사용자의 자연어 질문을 해석해 어떤 경로(SQL / Cypher / 분석)를 실행할지 결정하는 역할입니다.

### SQL Agent
PostgreSQL에 질의해 필터링, 정렬, 집계 같은 정형 데이터 처리를 담당하는 역할입니다.

### Cypher Agent
Neo4j에 질의해 관계 탐색, 그룹 탐색, 계보 탐색을 담당하는 역할입니다.

### Synthesis Agent
여러 실행 결과를 사람에게 읽기 좋은 최종 답변으로 정리하는 역할입니다.

## 현재 구현 단계 관련 용어

### UC1
최신 웨이퍼 조회 유스케이스입니다.

### UC2
조건 필터링 + 기본 통계 유스케이스입니다.

### UC3
동일 기간 / DOE 스타일 그룹 탐색 유스케이스입니다.

## 문서 읽기 팁

현재 FabGraph는 thin-slice MVP 단계이므로, 문서에는 장기 구조와 현재 구현이 함께 섞여 있습니다.  
따라서 문서를 읽을 때는 아래 구분을 염두에 두는 것이 좋습니다.

- **현재 동작하는 것**: README, STATUS.md, 테스트/실행 결과
- **앞으로 구현할 구조**: PRD, architecture, roadmap, ADR
