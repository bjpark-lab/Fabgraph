# FabGraph 문서 모음

이 디렉터리는 FabGraph의 제품 기획, 아키텍처, 설계 결정, 개발 계획 문서를 모아두는 곳입니다.

## 디렉터리 구성

- `product/`
  - PRD 및 사용자 가치 정의
- `architecture/`
  - 시스템 구조, 에이전트 구조, API 계약, 데이터 모델
- `decisions/`
  - ADR(Architecture Decision Record)
- `planning/`
  - 프로젝트 구조, 로드맵, 스프린트 계획

## 참고

대부분의 문서는 초기 설계 문서를 FabGraph 맥락에 맞게 가져와 이름과 표현을 조정한 것입니다.  
현재 구현 상태와 100% 일치하지 않을 수 있으므로, 문서를 볼 때는 **현재 코드 상태와 함께 확인**하는 것이 좋습니다.
